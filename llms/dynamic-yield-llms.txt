# Dynamic Yield

> Dynamic Yield (a Mastercard company) is an experience optimization and personalization platform — "Experience OS" — that individualizes content, product recommendations, offers, search, and messaging across web, mobile app, email, and kiosk channels. It is MACH Alliance certified and exposes server-side Experience APIs, a Product Feed API, a User Event API, Recommendation APIs, a Search API, and the Shopping Muse AI shopping-assistant API, plus native mobile SDKs. Server-side APIs authenticate with a DY-API-Key header.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface at dy.dev; it is not a provider-published file.
